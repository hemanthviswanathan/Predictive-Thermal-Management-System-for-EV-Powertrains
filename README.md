# Predictive-Thermal-Management-System-for-EV-Powertrains
An edge-computed, predictive thermal management system designed for high-density Electric Vehicle (EV) battery packs and power electronics. Built on an ESP32 microcontroller, this project uses discrete derivative calculus ($\frac{dT}{dt}$) and Exponential Moving Average (EMA) signal filtering to anticipate thermal runaway and activate solid-state cooling 12 to 15 seconds earlier than traditional thermostats.Key FeaturesPredictive Derivative Control ($\frac{dT}{dt}$): Evaluates thermal velocity every 1.0 second inside a hardware timer interrupt.Signal Noise Suppression: Applies an Exponential Moving Average (EMA, $\alpha=0.3$) filter to eliminate high-frequency EMI noise from power converters.Galvanic Electrical Protection: Interfaces the 3.3V ESP32 microcontroller with high-current 12V cooling fans using an opto-isolated solid-state relay circuit.Fail-Safe Robustness: Features open-circuit and NaN fault detection that automatically forces 100% continuous cooling during sensor failure.Hardware Architecture & PinoutComponentESP32 Pin / RailFunctionBMP280 VCC3.3VSensor Power SupplyBMP280 GNDGNDCommon Ground ReferenceBMP280 SDAGPIO 21I2C Serial Data LineBMP280 SCLGPIO 22I2C Serial Clock LineRelay VCCVIN (5V)Relay Coil Electromagnet PowerRelay GNDGNDCommon Ground ReferenceRelay INGPIO 53.3V Logic Trigger OutputRelay COM / NOExternal 12V SupplyIsolated 12V Cooling Fan Circuit LoopMathematical Model1.
