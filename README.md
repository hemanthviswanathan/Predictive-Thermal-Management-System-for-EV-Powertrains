# Predictive-Thermal-Management-System-for-EV-Powertrains
An edge-computed, predictive thermal management system designed for high-density Electric Vehicle (EV) battery packs and power electronics. Built on an ESP32 microcontroller, this project uses discrete derivative calculus ($\frac{dT}{dt}$) and Exponential Moving Average (EMA) signal filtering to anticipate thermal runaway and activate solid-state cooling 12 to 15 seconds earlier than traditional reactive thermostats.🚀 Key FeaturesPredictive Derivative Control ($\frac{dT}{dt}$): Evaluates thermal velocity every 1.0 second inside a non-blocking hardware timer interrupt.Signal Noise Suppression: Applies an Exponential Moving Average (EMA, $\alpha=0.3$) filter to eliminate high-frequency EMI noise from power converters.Galvanic Electrical Protection: Interfaces the 3.3V ESP32 microcontroller with high-current 12V cooling fans using an opto-isolated solid-state relay circuit.Fail-Safe Robustness: Features open-circuit and NaN fault detection that automatically forces 100% continuous cooling during sensor hardware failure.⚡ Hardware Architecture & PinoutComponentESP32 Pin / RailFunctionBMP280 VCC3.3VSensor Power SupplyBMP280 GNDGNDCommon Ground ReferenceBMP280 SDAGPIO 21I2C Serial Data LineBMP280 SCLGPIO 22I2C Serial Clock LineRelay VCCVIN (5V)Relay Coil Electromagnet PowerRelay GNDGNDCommon Ground ReferenceRelay INGPIO 53.3V Logic Trigger OutputRelay COM / NOExternal 12V SupplyIsolated 12V Cooling Fan Circuit LoopNote: The sensor is powered strictly via 3.3V to protect the MCU's GPIO pins, while the relay coil utilizes the 5V VIN rail to guarantee physical actuation.🧮 Mathematical Model1. Digital Noise Filtering (EMA)To prevent the fan from chattering due to electrical noise, raw data is smoothed:
$$T_{\text{filtered}}[k] = \alpha \cdot T_{\text{raw}}[k] + (1 - \alpha) \cdot T_{\text{filtered}}[k-1]$$
(Where smoothing factor $\alpha = 0.3$)2. First-Order Derivative CalculusThe ESP32 calculates the continuous rate of temperature change:
$$\frac{dT}{dt} \approx T_{\text{filtered}}[k] - T_{\text{filtered}}[k-1]$$3. Actuation ConditionThe cooling relay activates preemptively if:
$$\left(\frac{dT}{dt} \ge 1.0^\circ\text{C/s}\right) \lor \left(T_{\text{filtered}} \ge 45.0^\circ\text{C}\right)$$🛠️ How to Build & FlashInstall VS Code and the PlatformIO extension (or use the Arduino IDE with the ESP32 v3.0 core).Clone this repository:git clone https://github.com/YOUR_USERNAME/predictive-ev-thermal-management.git
